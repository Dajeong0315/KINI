# KINI AWS 서버 사양과 무료 크레딧 사용 계획

확인일: 2026-11-26 (한국 시간). 서버 생성·유료 전환·결제·실제 모델 호출 없음.

추가 확정: 운영 목표는 2026-12-22 발표 종료까지다. 장기 비교표는 참고로 보존하며 [발표일까지 27일 예산·배포 명세](클라우드_배포_연결_명세_v1.md)를 우선 적용한다. 평소 최대 8시간·발표일 종일 운영 가정의 기본 소모는 USD 32.39다.

## 1. 이번 단위의 결정

API·LangChain·Ollama를 한 대에서 실행할 **시연용 기준 사양은 Sydney ap-southeast-2의 m7i-flex.large, 2 vCPU, RAM 8 GiB, gp3 40 GB, 무료 라이선스 Linux**로 정한다. 평소 서버는 중지하고 하루 4시간 이내 개발·시연 가동을 기본 예산으로 잡는다. Supabase 답변을 기다리지 않고 무료 한도 기준으로 설계를 진행한다. 실제 용량·VM 생성 가능 여부와 모델 성능은 배포 단계에서 확인한다.

현재 AWS 프로젝트는 시드니로 연결된다. 이번에는 다른 지역 활성화나 유료 플랜 전환을 하지 않았다. 실제 EC2 인스턴스 유형 목록에서 m7i-flex.large의 Free tier eligible=true, x86_64, 2 vCPU, RAM 8 GiB, Linux USD 0.1197/h를 확인했다. EC2 대시보드의 실행 중 인스턴스·볼륨은 각각 0개였다. 유형 목록 조회는 가용 용량·quota·실행 성공의 보장이 아니다.

## 2. 서비스 구성과 메모리 계획

| 구성 | 초기 설계 |
|---|---|
| OS·API | Ubuntu 24.04 LTS 등 라이선스 비용 없는 x86_64 Linux. reverse proxy와 Python API |
| LangChain | API 내부 흐름 연결. 별도 대형 서버·별도 DB를 만들지 않음 |
| Ollama | 내부 loopback 또는 컨테이너 내부망. 브라우저·인터넷에 모델 포트 직접 공개 금지 |
| 모델 | 기존 3B/4B 양자화 모델 중 한 개만 로드. 초기 검증은 qwen2.5:3b-instruct-q4_K_M 후보, 운영 모델 선정과는 구분 |
| 동시성 | 추론 1개씩, 초기 context 2048. 요청 대기·시간 초과와 실제 지연을 측정 |
| DB | Supabase에 저장. 사용자 기기 DB나 EC2의 별도 영속 SQLite를 운영 원본으로 추가하지 않음 |
| 디스크 | gp3 40 GB에 OS·이미지·모델 1개·제한된 로그. 음성·영상 원본 무제한 적재 금지 |
| 네트워크 | Tailscale 용도·플랜 확인 후 팀 시연 접근. 외부 서비스 통신은 HTTPS, Ollama는 내부 전용 |
| 제외 | GPU, NAT Gateway, Load Balancer, RDS, 상시 다중 모델, 동시 YOLO·대규모 STT 추론 |

메모리 배분은 모델·context에 3~5 GiB, OS·API·LangChain에 1~2 GiB, 나머지를 여유로 보는 **예상치**다. 실제 메모리는 미측정이며 8 GiB에서 4B가 항상 안정적이라고 보장하지 않는다. 모델을 여러 개 로드하지 않고 API worker 수와 추론 동시성을 제한해 시작한다. 부족하면 먼저 작은 모델·context를 검토하며 자동으로 더 큰 유료 서버로 올리지 않는다.

m7i-flex는 지속 100% CPU 전용 장비가 아니며 baseline 40%와 가변 성능 특성이 있다. 짧은 검증용 요청의 후보이지 지속 고부하 LLM 운영 성능을 검증한 것은 아니다. 기존 PC의 모델 비교 수치를 AWS 지연으로 재사용하지 않는다.

대안 c7i-flex.large는 4 GiB에 USD 0.11072/h라 메모리 여유에 비해 절감폭이 작다. t3.small은 2 GiB에 USD 0.0264/h지만 기존 Ollama와 API 동시 실행 기준으로 채택하지 않는다. API만 따로 실행하는 후속 분리안에서는 검토할 수 있다.

## 3. 단가와 계산 조건

금액은 USD·세전 단순 추정이다. 추가 프로모션·무료 IP 등 확인하지 않은 할인은 빼지 않는다. AWS 계정의 잔여 크레딧은 약 USD 100, 무료 플랜 종료일은 2027-05-09이다. 2026-11-26부터 날짜 차이는 164일이며 계정 화면은 조회 시각에 따라 164~165일로 표시됐다.

| 항목 | 확인 단가 | 예산 조건 |
|---|---:|---|
| m7i-flex.large Linux Shared On-Demand | 0.1197/h | 실행 시간만 계산. 예약·Spot·유료 OS 없음 |
| 공인 IPv4 1개 | 0.005/h | 실행 시간에만 자동 할당된 주소 사용 가정. 고정 Elastic IP를 유지하지 않음 |
| gp3 40 GB | 0.096/GB-month | 40 × 0.096 = 3.84/월. 중지 중에도 디스크는 유지·소모 |
| 기타 | 별도 여유분 | 트래픽·스냅샷·로그·세금·가격 변동·다른 프로젝트 비용 등 |

AWS 공식 EC2 가격표 버전 20261124231417, 게시일 2026-11-24T23:14:17Z의 Sydney CSV에서 BoxUsage 행과 gp3 VolumeUsage 행을 추출했다. 예약 행의 0달러를 실행 가격으로 사용하지 않았다.

월 30일·디스크 1개·공인 IP 1개 기준:

`월 예상 소모 = (0.1197 + 0.005) × 하루 실행 시간 × 30 + 3.84`

| 운영 | 월 기본 소모 | USD 100 산술 소진 기간 | USD 20 남길 때의 예산 기간 |
|---|---:|---|---|
| 매일 2시간 | 11.32 | 약 265일이나 무료 플랜 종료일이 더 빠름 | 산술 212일이나 무료 플랜 종료일이 더 빠름 |
| 매일 4시간 | 18.80 | 약 160일, 약 5.3개월 | 약 128일, 약 4.3개월 |
| 매일 8시간 | 33.77 | 약 89일, 약 3개월 | 약 71일, 약 2.4개월 |
| 24시간 상시 | 93.62 | 약 32일 | 약 26일 |
| 평일 22일 × 8시간 | 25.79 | 약 3.9개월 | 약 3.1개월 |

기간은 실제 지출 예측 보증이 아니다. 디스크는 전체 기간 유지, IPv4는 실행 중에만 보유하는 가정이다. 최종 기간은 크레딧 소진과 2027-05-09 중 빠른 시점까지다. AWS 이외의 OpenAI 호출은 별도 잔액 USD 8.14에서 소모하며 위 표에 포함하지 않는다. Tailscale을 사용해도 IPv4·디스크·EC2 자체 비용이 사라지는 것은 아니다.

권장 예산은 **하루 4시간 이내, AWS 잔액 USD 20을 여유로 남기는 약 4개월 운영**이다. 이는 예산 목표이며 아직 자동 중지나 예산 알림을 생성하지 않았다. AWS 예산 알림만으로 강제 지출 상한이 되는 것은 아니며 별도 중지 정책을 구현·확인해야 한다.

## 4. Supabase 무료 한도 기준 임시 계획

현재 실제 사용량은 소유자 확인 대기이며 이 단계의 진행 조건에서 제외한다. 무료 플랜 DB 500 MB·Storage 1 GB·egress 5 GB 기준으로 다음 논리 예산을 잡는다. 실제 남은 용량을 의미하지 않는다.

| DB 영역 | 임시 예산 |
|---|---:|
| 공개 식품·레시피 카탈로그 | 200 MB |
| 가족·재고·식사·피드백 등 개인 데이터와 관련 인덱스 | 100 MB |
| 플랫폼·인증·기타 시스템·증가 여유 | 50 MB |
| 여유 공간 | 150 MB |
| 합계 | 500 MB |

전체 350 MB를 경고 검토점, 400 MB를 신규 대량 적재 중단 검토점으로 삼는다. 기존 코드의 카탈로그용 guard가 신규 개인 데이터 쓰기까지 자동 보호한다고 가정하지 않는다. 검진표·음성·이미지는 DB 행에 원본을 넣지 않고, 추후 비공개 Storage가 필요한 경우에만 보관 기간을 정한다. 첫 배포는 합성 데이터·소수 사용자로 시작한다.

기존 보고서의 166.8 MB는 과거 측정값이어서 현재 잔여량으로 차감하지 않았다. 공개 카탈로그 복제·release 교체·마이그레이션 임시 공간은 위 한도 내 별도 검토 대상이다. 실제 이전 전 소유자 숫자를 받으면 이 예산과 대조한다. 가정 기반 설계가 실제 적재 권한이나 여유 공간 확인을 대신하지 않는다.

## 5. 완료와 다음 한 단위

**이번 단위 완료:** AWS 무료 적용 대상과 공식 가격 확인, 시연용 기준 사양 선정, 가동 시간별 크레딧 소모 계산, Supabase 가정 예산 작성.

**배포 명세 작성 완료:** [클라우드 배포·연결 명세](클라우드_배포_연결_명세_v1.md)에 구성·어댑터·권한·모델 내부 연결·검증 단위를 정리했다. 다음 별도 구현은 PostgreSQL 저장·권한 기반이며 서버 생성·유료 전환은 수행하지 않았다.

실제 생성 후 별도로 확인할 항목은 계정 quota·가용 용량·RAM peak·첫 로딩/재요청 지연·에러 시 후보 차단·중지 후 디스크 비용·개인정보 로그 차단이다. 현재 결과를 실제 Ollama 운영 검증 완료로 표시하지 않는다.
