# 업로드 음성 통합 테스트셋

이 문서는 준비된 한국어 음성 파일로 `업로드 → faster-whisper 전사 → 규칙/재고 응답 → Piper WAV` 흐름을 확인하기 위한 수동 테스트셋이다. 영양 균형을 계산해 메뉴를 추천하는 기능은 아직 범위 밖이므로, 해당 평가는 하지 않는다.

원본 음성 파일은 `samples/audio/`에만 임시로 보관하고 Git에 추가하지 않는다. 파일명은 아래 ID를 앞에 붙인다. 예: `V01_inventory_clear.wav`.

## 녹음 조건

- 한 문장씩, 보통 말하기 속도로 또렷하게 녹음한다.
- 먼저 조용한 환경에서 WAV 또는 MP3로 녹음한다. 이후에만 약한 생활 소음·빠른 발화 사례를 추가한다.
- 마이크와 입 사이 거리는 약 20~30cm로 유지한다.
- 파일 하나에는 질문 하나만 넣는다. 앞뒤 무음은 각각 1초 정도면 충분하다.
- 각 파일을 업로드한 뒤 화면의 **전사 결과**, **답변**, **답변 음성 만들기** 결과를 모두 기록한다.

| --- | --- | --- | --- | --- |
| V01 | `떡이 얼마나 있어?` | `떡`, `얼마나`가 맞게 인식 | 떡과 `300g`가 포함 | 수량·재고 사실 확인 |
| V02 | `냉장고에 뭐가 있어?` | `냉장고`, `뭐가 있어`가 맞게 인식 | 떡·버섯·고추장·계란이 모두 포함 | 재고 목록 |
| V03 | `떡과 고추장으로 매콤한 메뉴를 추천해줘.` | `떡`, `고추장`, `매콤한`, `추천`이 맞게 인식 | `고추장 떡볶이 스타일` 또는 안전한 식약처 후보. `꼬막`은 포함되면 실패 | 기본 양념 가정 메뉴 |

| V05 | `떡 먹어도 안전해?` | `떡`, `안전`이 맞게 인식 | 반드시 `냄새·색·점액을 확인하고 의심되면 버리세요` 포함 | 식품 안전 고정 문구·Ollama 우회 |
| V06 | `사과 있어?` | `사과`, `있어`가 맞게 인식 | 사과가 재고에 있다고 말하지 않음 | 없는 재고 방지 |
| V07 | `버섯은 어디에 보관돼 있어?` | `버섯`, `어디`, `보관`이 맞게 인식 | 버섯과 보관 위치가 포함 | 위치 사실 확인 |

## 음성 인식 강건성 테스트

아래는 핵심 테스트가 모두 통과한 뒤 수행한다. 답변 내용보다 전사 결과가 의도한 질문의 핵심어를 유지하는지가 우선이다.

| ID | 녹음 조건 및 문장 | 합격 기준 |
| --- | --- | --- |
| V08 | V03 문장을 평소보다 조금 빠르게 말하기 | `떡`, `고추장`, `매콤`, `추천` 중 네 핵심어가 유지 |
| V09 | V01 문장을 약한 생활 소음 환경에서 말하기 | `떡`과 `얼마나`가 유지. 실패하면 파일 형식·마이크 거리·소음을 기록 |
| V10 | 3~5초 무음 파일 업로드 | 전사문이나 답변을 지어내지 않고 사용자 친화적 오류 표시 |
| V11 | 지원하지 않는 확장자 파일 업로드 | `지원하지 않는 음성 파일 형식` 오류 표시 |

## Piper WAV 확인

V01, V03, V05 각각의 답변을 받은 뒤 **답변 음성 만들기**를 누른다.

- 브라우저 플레이어에서 재생된다.
- 다운로드 파일 확장자가 `.wav`다.
- 첫 문장과 숫자(`300g` 등), 안전 문구가 알아들을 수 있게 재생된다.
- 실패 시 화면 오류 문구만 기록하고 API 키·환경 변수·내부 경로는 기록하지 않는다.

## 권장 진행 순서

1. V01~V07을 조용한 환경에서 WAV 또는 MP3로 녹음·업로드한다.
2. 전사가 틀리면 답변 품질을 평가하지 말고, 실제 전사문과 핵심어 누락만 기록한다.
3. 전사가 맞은 사례만 답변 기준과 WAV 재생까지 평가한다.
4. 핵심 7건이 안정적일 때 V08~V11을 수행한다.
5. 결과는 원본 오디오 대신 이 문서의 기록 양식 또는 별도 요약 문서에 남긴다.
