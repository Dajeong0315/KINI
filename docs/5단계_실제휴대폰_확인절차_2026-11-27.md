# 5단계 실제 휴대폰 확인 절차

2026-11-27 KST. PC의 모바일 화면 크기 시험과 별도로 실제 휴대폰·네트워크에서 확인한다.

대상: Tailscale에 연결한 휴대폰 → `https://kini-b-20261127.tailacd652.ts.net:8443/mobile`.
시연 계정의 로그인 이름·비밀번호·가구 ID는 PC의 보호된 파일
`C:\Users\aicam\AppData\Local\KINI\SupabaseSetup\586ce9ad5053\demo-login.json`에서 확인한다.
키·비밀번호·토큰·파일 내용을 채팅으로 보내지 않는다. 이 절차는 합성 시연 가구 전용이며 실제 식사나 실제 재고 입력으로 해석하지 않는다.

1. 로그인하고 홈에서 **합성 참여자**를 선택한다.
2. **식재료 → + 식재료 추가**에서 정확한 이름 `당근, 뿌리, 생것`, 중량 `10`, 단위 `g`를 입력한다. 확인란을 체크하고 **입고 확정**한다. 기존 재고를 덮어쓰지 않고 추가되는지 확인한다.
3. **메뉴 추천**에서 같은 참여자를 선택하고 추천한다. 기본 조리 시간 30분을 유지한다. `[시연] 닭가슴살 당근밥 · 원재료 기준` 메뉴를 선택한다.
4. 재료·데이터 확인란을 체크하고 **조리 시작**한다. 변경할 정확한 재료명에 `당근, 뿌리, 생것`, 이번 조리 총 사용량에 `40`을 입력하고 **변경 및 영양 재검증**을 누른다. 당근 40g과 갱신된 영양을 확인한다.
5. **조리 완료 · 섭취량 확인**에서 실제 섭취량 `0.5`인분을 입력한다. **수동 출고량 확인**에서 재료·중량을 보고 미출고 확인란을 체크한 뒤 **수동 출고 확정**한다. 이미 확정한 재료를 새 출고로 다시 등록하지 않는다.
6. 실제 사용량·개인 섭취량 확인란을 체크하고 **서버에 식사 기록 저장**한다. 영양 관리로 이동해 새 기록의 **기록 상세**를 연다. 이 조리안의 0.5인분 열량은 **196.85 kcal**다. 원재료 기준 추정치이며 조리 보존율은 반영하지 않았다.
7. 새로고침한 뒤 같은 계정·가구로 재로그인한다. 영양 관리에서 방금 저장한 날짜·기록 ID·0.5인분·영양값을 다시 확인한다.

요청 처리 중 버튼이 비활성 상태가 되며 저장은 약 15초 가까이 걸릴 수 있다. 응답을 받지 못한 경우 새 출고나 새 조리를 만들지 말고 오류 문구와 마지막 성공 단계를 알려준다. 자동 재조회·동일 이벤트 재시도는 기존 클라이언트 계약을 따른다.

전달할 결과는 **휴대폰 기종/브라우저, 통과 여부, 마지막 성공 단계 또는 오류 문구**다. 비밀번호·세션 토큰은 포함하지 않는다. 기기에서 수행하지 않은 상태를 통과로 기록하지 않는다.
