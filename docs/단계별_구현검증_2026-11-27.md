## 2단계: 실제 의존성으로 중단

기존 provider 계약은 확인 가능하다. `RecommendationNutritionProvider`는 검토된 재료 매핑,
현재 active release, published 상태, 승인된 source를 요구한다. 이름·숫자 ID로 매핑을 추측하지 않는다.
`deploy/README.md`에 public cloud 카탈로그와 앱 스키마의 UUID/JSONB·영양 구조 차이가 명시되어 있다.
하지만 실제 public 스키마·승인 매핑·읽기 권한을 지금 접속하여 확인할 수 없다.

- 서버 `/etc/kini-b/runtime.env`: PostgreSQL URL 없음. `/etc/kini/server.env`도 없음.
- 원본 작업 폴더 `.env`와 현재 프로세스 환경: DB/Supabase 접속 항목 없음. 비밀 값은 출력하지 않았다.
- 사용 가능한 플러그인에 Supabase/SQL 연결 도구 없음.
- Aside 업데이트 실패: 설치기에서 Windows 판별 오류. CUA 브라우저 inventory도 browser access host unavailable.
  Supabase 로그인·메타데이터를 확인하지 못했으며 과거 보고서의 schema 상태를 현재 실측으로 쓰지 않는다.

### 보존 여부를 결정해야 하는 로컬 SQLite

원본 작업 폴더 `app/data/kini.sqlite3`가 실제 존재한다. 읽기 전용으로 metadata·집계만 확인했다.
258,048 bytes, 테이블 44개, 가구 1·구성원 4·재고 9행, 식사/섭취/조리 기록은 검사 대상 테이블에서 0행.
foreign_key_check 위반 0개. 실제 입력인지 폐기 가능한 데모인지 집계만으로 판단할 수 없다.
서버의 synthetic-only DB와 별개다. 내용·원본 DB를 새 worktree나 Git에 복사하지 않았다.

보존 결정 후 실행할 계획:

1. 보호된 비저장소 경로로 `scripts/backup_sqlite.py` snapshot 생성, WAL 포함 integrity·SHA256 확인.
2. 원본 스키마·컬럼·FK와 대상 private 스키마를 대조하고 보존 범위를 확정. 세션 토큰은 이전 제외.
3. 별도 합성 DB에서 UUID·boolean·timestamp·sequence 변환과 관계 보존 검증.
4. 건수·FK·재고량·단위·영양 기준량·출처를 검증하고, 원본을 보존한 채 이전 실행 범위 승인을 확인.
5. 운영 쓰기 전환·migration은 이번 계획만으로 실행하지 않음.

### 필요한 요청과 재개 위치

이전 보존 결정이 필요한 실제 데이터 이전은 답변 전 실행하지 않는다.

소유자만 승인할 수 있다는 규칙은 확인되지 않았다. 기존 source 권리 승인과 기술적 재료 매핑 검토는 구분한다.

`app/services/data_import/cloud_plan.py`는 레시피당 전체 ingredients_text를
`ingredient_name=미분해 재료 목록`, line_no=1로 보존하고 quantity/unit은 채우지 않는다.
따라서 1,152행은 1,152개의 검토 완료 재료 연결이 거절된 상태가 아니라 아직 분해되지 않은 목록이다.
`db/supabase_food_catalog.sql`의 주석도 reviewed가 알레르기 안전이나 로컬 가구 연결을 보증하지 않는다고 명시한다.
앱 provider는 별도 reviewed_at·명시적 외부 ID 연결을 요구하지만 특정 담당자의 승인을 요구하지는 않는다.

### 실제 표본 직접 검토

## 2단계 구현 재개 결과

public 직접 읽기 어댑터·private 전용 명시적 연결 migration 009·추천 출처 표시·실제 연결용

상세 변경·테스트·운영 적용 전 경계는 [2단계 구현 기록](Supabase_읽기어댑터_2단계_2026-11-27.md)을 따른다.
원본 데이터·서버·실제 Supabase DDL/DML은 변경하지 않았으며 커밋·푸시는 수행하지 않았다.
카탈로그 조회 권한이나 포괄적 매핑 승인을 이유로 막힌 상태가 아니다.
이제 실제 앱 연결을 위해 private schema/역할 준비와 migration 적용의 구체적인 승인 범위가 필요하다.
2단계를 실제 카탈로그 추천 실접속 완료로 표시하지 않는다.
