# iPad·휴대폰에서 프로토타입 열기

## 전제 조건

- 개발 PC와 iPad/휴대폰을 같은 Wi-Fi에 연결한다.
- 개발 PC의 방화벽에서 개인 네트워크의 Python 통신을 허용한다.
- 이 방법은 개발 중인 Flask 프로토타입을 Safari 또는 모바일 브라우저로 여는 방법이다. 실제 LG ThinQ 앱 내부 탑재는 LG의 SDK·파트너 권한·배포 정책 확정 후 별도 구현한다.

## 1. 개발 PC에서 서버 실행

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행한다.

```powershell
Set-Location C:\Users\aicam\Desktop\Project_3
.\.venv\Scripts\Activate.ps1
$env:APP_HOST = "0.0.0.0"
$env:APP_PORT = "5000"
python -m app.main
```

`0.0.0.0`은 같은 Wi-Fi의 다른 기기에서 개발 PC에 접속할 수 있도록 하는 개발용 설정이다. 외부 인터넷에 공개하지 않는다.

## 2. 개발 PC의 Wi-Fi IPv4 주소 확인

새 PowerShell 창에서 실행한다.

```powershell
ipconfig
```

Wi-Fi 어댑터의 `IPv4 주소`를 확인한다. 예: `192.168.0.25`

## 3. iPad에서 열기

1. iPad를 개발 PC와 같은 Wi-Fi에 연결한다.
2. Safari 주소창에 `http://개발PC_IP:5000`을 입력한다. 예: `http://192.168.0.25:5000`
3. 기본으로 냉장고 디스플레이용 다크 화면이 표시된다.
4. 우측 상단의 `냉장고 화면` 버튼을 눌러 ThinQ 앱용 밝은 화면으로 전환할 수 있다.
5. Safari 공유 메뉴에서 `홈 화면에 추가`를 선택하면 앱처럼 실행할 수 있다.

## 4. 휴대폰에서 열기

1. 휴대폰을 개발 PC와 같은 Wi-Fi에 연결한다.
2. Safari 또는 Chrome에서 `http://개발PC_IP:5000`을 연다.
3. 화면 폭이 660px 이하이면 ThinQ 앱용 모바일 화면이 자동 적용된다.
4. 모바일 하단 메뉴에서 오늘, 추천, 냉장고, 리포트, 프로필을 이동한다.
5. 홈 화면 추가 기능을 사용하면 브라우저 주소창 없이 실행할 수 있다.

## 5. 기기별 화면 기준

| 환경 | 기본 디자인 | 주 사용 기능 | 민감 정보 표시 |
| --- | --- | --- | --- |
| 냉장고 디스플레이 / 세로 iPad | 어두운 유리 패널, 큰 글자, 위젯형 카드 | 오늘 메뉴 결정, 재료 소진 알림, 음성 조리 지원 | 개인 건강 수치·상세 제한은 숨김 |
| ThinQ 모바일 | 밝은 표면, ThinQ 계열의 마젠타 강조색, 하단 탭 | 개인 기록, 리포트, 프로필·전략 관리 | 본인 인증·선택 후 상세 표시 |

## 6. 현재 연결된 API

| API | 현재 화면 사용처 |
| --- | --- |
| `GET /api/inventory` | 냉장고 재료 목록 |
| `GET /api/nutrition?food_name=` | 재료별 영양성분 패널 |
| `POST /api/chat` | 조리 중 AI 질문 응답 |

## 7. 다음 백엔드 연동 항목

```text
GET  /api/recommendations       # 규칙 엔진이 계산한 메뉴 후보·점수·근거
GET  /api/recipes/{recipe_id}  # 원본 레시피와 검증된 맞춤 버전
POST /api/cooking-changes      # 조리 중 변경사항 초안·검증 결과
POST /api/meal-records         # 개인별 실제 섭취량 저장
GET  /api/reports              # 개인·가족 영양 리포트
GET  /api/profiles             # 가족·개인 프로필과 전략
```

각 응답에는 `recommendation_rules_version`, `nutrition_db_version`, `nutrition_confidence`를 포함한다.

## 8. 접속 문제 해결

| 증상 | 확인할 사항 |
| --- | --- |
| 휴대폰에서 접속 불가 | 같은 Wi-Fi인지, URL에 `127.0.0.1`이 아닌 PC IPv4 주소를 썼는지 확인 |
| 방화벽 경고 | 개인 네트워크에서 Python 통신을 허용 |
| 화면이 예전 상태 | 브라우저를 새로고침하거나 캐시를 삭제 |
| 모바일 화면이 아닌 경우 | 브라우저 폭을 줄이거나 우측 상단 화면 전환 버튼 사용 |
| 외부 네트워크에서 접속 필요 | 임시 터널·HTTPS·인증 정책을 별도 검토. 개발 서버를 인터넷에 직접 노출하지 않음 |
