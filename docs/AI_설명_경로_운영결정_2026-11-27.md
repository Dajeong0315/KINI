# Ollama 검사·OpenAI 설명 경로 운영 결정

결정·코드 확인일: 2026-11-27 (한국 시간). 현재 로컬 체크아웃 기준이며 서버 적용 여부는 미확인이다.

| 항목 | 이번 단계 결정 |
|---|---|
| Ollama 개인정보 보조 검사 → OpenAI 설명 연결 | 비활성화. 규칙 기반 개인정보 게이트와 로컬 고정 설명 사용 |
| Ollama 보조 검사 모델 | 이번 단계에는 사용하지 않음. 후속 사용자 결정에 따라 로컬 요청 해석·채팅 기본 모델은 `qwen2.5:3b-instruct-q4_K_M` 사용 |
| OpenAI 설명 모델 | 사용하지 않음. `OPENAI_RECOMMENDATION_MODEL` 미설정 |
| 실제 시험 호출 수 | Ollama 보조 검사 0회, OpenAI 설명 0회. 자동 재시도 포함 |
| OpenAI API 비용 상한 | 이번 단계 USD 0. 서버·기존 Ollama 운영비와 별개 |
| 실행 설정 | `KINI_USE_OPENAI=0` 유지. 키 등록만으로 활성화하지 않음 |

## 결정 근거

`app/services/ai/recommendation_chain.py`는 모델의 summary와 reason 문장을 버리고 로컬 고정 문구만 반환한다. 따라서 현재 구현에서 유료 설명 호출을 켜도 사용자에게 보이는 설명은 개선되지 않으며, 네트워크 오류 시 추천이 `api_error`가 될 수 있다.

`app/services/ai/privacy_gateway.py`는 결정적 허용 목록 검사를 수행한다. `LocalPrivacyInspector`는 선택 인터페이스이며 기본 경로에는 실제 Ollama 검사기가 연결되어 있지 않다. 기존 Ollama의 요청 해석·채팅 기능을 개인정보 검사 구현 완료로 간주하지 않는다.

현재 코드에는 누적 시험 호출 수·비용을 강제하는 제한기가 없다. 이번 0회 결정은 외부 경로 비활성화로 지킨다. 유료 시험으로 전환할 때에는 모델과 호출 수를 다시 정하고, 재시도·동시 요청·프로세스 재시작에도 적용되는 한도와 출력 토큰 제한을 먼저 구현한다.

## API 키 등록 상태와 서버 설정

키 값을 출력하지 않고 확인한 결과 로컬 `.env`와 현재 프로세스 환경에는 `OPENAI_API_KEY`가 없고 `KINI_USE_OPENAI=0`이다. 사용자가 지정한 서버는 Tailscale SSH `ubuntu@100.81.162.14`, 등록 파일은 `/etc/kini-b/runtime.env`이다. 마지막 확인 시 키 미등록·별도 비밀 저장소 없음이라는 사용자 설명을 받았다. 이번 SSH 접속은 `Permission denied (publickey)`로 실패해 서버 키·설정·권한은 직접 확인하거나 변경하지 못했다. 로컬 `.env`를 서버의 보호된 설정으로 간주하지 않는다.

서버 환경 파일은 사용자 지정대로 소유자 `root`, 그룹 `kini-b`, 권한 `0640`을 유지한다. 관리자는 서버에서 `sudoedit /etc/kini-b/runtime.env`로 기존 내용을 보존하며 키를 입력한다. 이번 결정에서 `OPENAI_RECOMMENDATION_MODEL`은 미사용·미설정이며 `KINI_USE_OPENAI=0`을 유지한다. 키는 관리자의 서버 보안 입력으로 전달하고 채팅·Git·명령 인수·로그·브라우저로 옮기지 않는다. 키 원본이 제공된 비밀 저장소에 없으므로 등록을 완료했다고 표시하지 않는다.

등록 후에는 값 노출 없이 파일 권한·서비스 참조·키 존재 여부만 확인한다. `KINI_USE_OPENAI=0`과 모델 미설정을 유지하고, 키 검증을 이유로 실제 API를 호출하지 않는다.

## 검증 범위

후속 사용자 결정(같은 날): 로컬 기본 모델을 Qwen 2.5 3B로 변경했다. 실제 로컬 `.env`, 코드의 기본값, `.env.example`, README 설치 명령과 기본 모델 회귀 테스트를 맞췄다. 로컬 Ollama `/api/tags`에서 정확한 모델 설치를 확인했다. 실제 추론 호출은 수행하지 않았으며 보조 검사·OpenAI 비활성/0회·USD 0 결정은 유지한다.

기존 `test_ai_privacy_chain.py`, `test_recommendation_ollama_settings.py`, `test_ollama_model.py`의 34개 테스트 통과(9.37초). `scripts/evaluate_ai_recommendations.py`의 오프라인 계약 평가 3건 모두 기대 결과와 일치했다. 합성·mock 검증이며 실제 Ollama 검사·OpenAI 품질·지연·토큰 사용량·과금 성능은 미측정이다. 실제 API 호출은 수행하지 않았다.
