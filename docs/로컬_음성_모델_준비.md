# 로컬 음성 모델 준비 및 문제 해결

## 개요

기본 음성 경로는 다음과 같이 로컬에서 처리한다.

```text
업로드 음성 파일 → faster-whisper 한국어 전사 → 기존 사실 기반 대화 처리 → Piper 한국어 WAV 생성
```

인터넷은 모델을 처음 준비할 때만 필요하다. 모델 준비가 끝나면 앱 런타임은 `models/` 안의 파일만 사용하며, STT/TTS 외부 API를 호출하지 않는다.

## Windows PowerShell 준비

```powershell
Set-Location C:\Users\aicam\Desktop\Project_3
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python .\scripts\download_voice_models.py
```

위 스크립트는 다음 파일을 준비한다.

```text
models/
  stt/
    small/                       # faster-whisper CTranslate2 모델
  tts/
    ko_KR-kss-medium.onnx        # Piper 한국어 음성 모델
    ko_KR-kss-medium.onnx.json   # Piper 음성 설정
```

모델 파일은 크기가 크므로 Git에 추가하지 않는다. `.gitignore`가 `models/` 전체를 제외한다.

## 실행

```powershell
python -m app.main
```

브라우저에서 `http://127.0.0.1:5000`을 열고, 준비된 WAV/MP3/M4A/WebM/OGG/MP4 파일을 업로드한다. 생성된 답변 음성은 WAV로 재생·다운로드할 수 있다.

## 로컬 음성 설정

`.env.example`에는 아래 기본값이 있다. 실제 `.env`의 비밀값은 문서나 로그에 기록하지 않는다.

```env
LOCAL_STT_MODEL=small
LOCAL_STT_DEVICE=cpu
LOCAL_STT_COMPUTE_TYPE=int8
LOCAL_STT_MODEL_DIR=models/stt
LOCAL_TTS_MODEL_DIR=models/tts
LOCAL_TTS_VOICE=ko_KR-kss-medium
```

값이 없으면 앱도 위 기본값을 사용한다. Intel UHD 630 환경에서는 CPU 및 `int8` 설정을 유지한다.

## 문제 해결

| 증상 | 확인 방법 |
| --- | --- |
| Whisper 모델 준비 오류 | `python .\scripts\download_voice_models.py`를 다시 실행하고 `models\stt\small\model.bin`이 있는지 확인한다. |
| Piper 음성 준비 오류 | `models\tts\ko_KR-kss-medium.onnx`와 `.onnx.json`이 모두 있는지 확인한다. |
| 전사 결과가 비어 있음 | 더 길고 선명한 한국어 음성 파일을 사용한다. |
| MP4/M4A 전사 오류 | faster-whisper가 사용하는 FFmpeg 오디오 디코딩 환경을 확인하고 WAV 또는 MP3로 다시 저장해 시도한다. |
| 시연 중 네트워크를 끊고 싶음 | 앱을 실행하기 전에 모델 준비를 끝내고, 식약처 레시피·영양 버튼은 사용하지 않는다. 재고·안전·Ollama·로컬 음성 경로는 로컬에서 동작한다. |

## 검증

모델을 다운로드하지 않는 코드 테스트는 다음처럼 실행한다.

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m compileall -q app
```
