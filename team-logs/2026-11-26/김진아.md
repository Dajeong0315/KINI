# 2026-11-26 | 김진아 기획 기록

## 오늘의 핵심

오늘은 현직자 멘토링을 통해 KINI의 차별화 방향과 구현·보안 검토사항을 구체화하고, 팀 내부 후속 회의에서 시연을 위한 개발 우선순위를 논의했다. 또한 DCX 분석 결과를 최종 산출문서의 데이터 수집 전략과 타깃 고객 장으로 정리했으며, 메인 서비스 흐름을 유지하면서 서브 페르소나별 요구를 목적별 모드로 확장하는 방향을 검토했다.

## 1. 현직자 멘토링 및 팀 내부 후속 논의

### 멘토링에서 확인한 방향

- KINI의 차별화는 단순히 냉장고의 기능을 늘리는 것이 아니라, 가족 구성원별 건강·영양·취향을 이해하고 다음 식사 행동까지 연결하는 **개인·가족 맞춤형 AI 영양 파트너**로 설명해야 한다.
- 메인 타깃인 30~40대 가족 식사 담당자를 선택한 근거를 DCX 분석 및 실제 생활 맥락과 더 명확히 연결할 필요가 있다.
- 사용자가 매번 먼저 기록해야 하는 구조를 넘어, 식사 시간이 지났는데 기록이 없거나 관리가 중단된 경우 AI가 먼저 확인하는 **선제적 상호작용**을 검토한다.
- 외식은 냉장고에서 자동으로 파악하기 어려우므로 ThinQ 앱 등 모바일 입력이 필요하며, 기록이 없을 때 냉장고가 사용자에게 확인하는 방식으로 보완할 수 있다.
- 카메라가 확실히 인식하지 못한 재료는 Unknown 상태로 두고 사용자의 확인을 받는 구조가 필요하다. 포장 식품은 라벨·텍스트 인식, 구매 식품은 영수증 OCR을 활용하는 방안도 검토한다.
- 대화형 AI, 카메라 인식, 디스플레이를 결합해 상호작용 완성도를 높이고, 장기적으로는 필요한 식재료를 음성으로 주문하는 에이전틱 AI까지 확장할 수 있다.
- Ollama와 같은 로컬 LLM을 반드시 냉장고 하드웨어에 직접 탑재할 필요는 없으며, LG 사내 서버나 전용 서버에서 처리하는 구조도 가능하다.
- 개인정보는 마스킹·익명화·암호화하고, 실제 데이터를 외부 AI에 직접 전달하지 않고 스키마나 필요한 조건만 제공해 로직을 얻는 방식도 검토할 수 있다.

### 팀 내부에서 정리한 구현 우선순위

- 로컬 기기·DB 중심 구조를 처음부터 고정하기보다, **클라우드 환경에서 핵심 기능을 먼저 구현하고 시연하는 방향**으로 의견을 모았다.
- 식재료 인식은 비전 모델을 다시 테스트해 기본 재료를 안정적으로 인식하는 것을 우선한다.
- 포장 식품은 이미지 인식에 라벨·텍스트 추출을 결합하고, 영수증 OCR은 재료 입력을 보완하는 후보 기능으로 검토한다.
- 우선 구현할 핵심 기능은 다음 두 가지로 정리했다.
  - 가족·개인 조건과 보유 재료를 반영한 레시피 추천
  - 조리 중 실제로 변경된 재료와 사용량을 반영해 기록과 영양 정보를 갱신하는 기능
- 클라우드에 저장할 정보의 범위, 비식별화 방식, Ollama 유지 여부, Supabase 및 서버 비용은 아직 최종 확정하지 않았다.

## 2. DCX 분석 결과의 최종 산출문서 반영

DCX 분석 결과를 최종 산출문서 형식에 맞춰 `Ⅲ. 데이터 수집 전략`과 `Ⅳ. 타깃 고객`으로 구체화했다.

### 데이터 수집 전략

- 목적: 가정 내 식재료 관리, 메뉴 선택, 영양 관리, 가족 구성원별 식생활 과정에서 반복되는 고객 고민을 탐색
- 채널: 네이버 블로그·카페·지식iN 검색 결과의 제목과 요약
- 검색 설계: 식재료 관리, 메뉴 선정, 영양 관리, 건강 맞춤 식단, 아이 편식 등 10개 영역·검색어 250개
- 분석 규모:
  - 최초 수집 74,161건
  - 전처리 후 61,130건
  - 26개 통합 군집에 34,492건 할당
  - 직접 경험·질문 및 일반 고민 중심의 고민 후보 18,345건
- 다국어 문장 임베딩과 HDBSCAN을 활용해 40개 원군집을 탐색한 뒤 의미 유사도에 따라 26개 주제로 통합했다.

### 메인·서브 타깃 정리

| 구분 | Actor | 핵심 생활 맥락 |
|---|---|---|
| 메인 | 가족 영양 관리형 | 가족 구성원별 건강·영양·취향 조건을 한 끼에 함께 반영 |
| 서브 1 | 자녀 맞춤 식단 관리형 | 편식·알레르기를 고려하면서 성장기 영양 균형 관리 |
| 서브 2 | 다이어트·체중 관리형 | 칼로리·단백질 목표를 확인하고 식단을 지속적으로 기록 |
| 서브 3 | 식재료 효율 관리형 | 재고와 남은 재료를 파악해 시간과 식비를 절약 |
| 서브 4 | 시니어 건강 식단 관리형 | 건강 정보를 이해하고 일상 식사에 쉽게 적용 |

- 메인 타깃은 **가족의 한 끼와 건강을 함께 책임지는 사람**으로 정의했다.
- 다이어트·식단 군집의 기회점수가 가장 높았지만, 해당 군집은 개인 건강식·단백질·칼로리·체중 관리가 넓게 결합된 결과다.
- 가족 영양 관리 문제는 건강 상태별 식단, 아이 편식·알레르기, 성장기 영양, 비타민·영양소, 식재료 관리와 메뉴 결정 등 여러 군집에 분산되어 나타났다.
- 단일 군집 순위만 보지 않고, 가족이 공동으로 사용하는 냉장고의 맥락과 여러 군집에서 반복된 가족 식생활 문제를 종합해 가족 영양 관리형을 메인 타깃으로 선정했다.

### 결과 해석 시 주의사항

- DCX 기회점수는 검색 문서의 언급 비중과 감성 분석을 활용한 상대적 탐색 지표이며, 전체 소비자의 수요 비율이나 설문 기반 만족도 점수가 아니다.
- 메인·서브 타깃은 분석 알고리즘이 직접 산출한 인구통계 집단이 아니라, 군집 결과와 서비스 사용 맥락을 결합해 정의한 기획 Actor다.
- 조리 중 대화를 통한 기록 자동화는 고객 발화에서 직접 검증된 요구가 아니라, 식사 기록 부담과 조리·기록 단절 문제를 해결하기 위한 기획 가설로 구분한다.
- 제출용 문서에는 현재 확인된 분석 결과만 사용하고, 기능 효과나 실제 사용자 수요가 입증된 것처럼 확대 해석하지 않는다.

## 3. 서브 페르소나를 목적별 모드로 확장하는 방향

- 서브 페르소나마다 별도의 서비스를 만드는 대신, **초기 설정 → 추천 → 조리 대화 → 식사 기록 → 리포트**라는 KINI의 공통 흐름은 유지한다.
- 기본 서비스 구현이 완료된 이후, 각 서브 페르소나의 목표에 맞춰 추천 기준·대화 방식·리포트 강조 항목을 바꾸는 목적별 모드를 추가하는 방향으로 논의했다.

| 대상 | 확장 모드 방향 | 주요 강조점 |
|---|---|---|
| 자녀 맞춤 식단 관리형 | 자녀 맞춤 모드 | 편식·알레르기, 성장기 영양, 가족 공통 메뉴 안에서의 대체안 |
| 다이어트·체중 관리형 | 목표 집중 모드 | 영양소·칼로리 목표 추적, 지속 동기, 식단 반복 방지 |
| 식재료 효율 관리형 | 식재료 효율 모드 | 재고 소진, 유통기한, 조리 시간과 식비 절약 |
| 시니어 건강 식단 관리형 | 건강 루틴 모드 | 건강 상태 기반 식사 관리, 쉬운 음성 사용, 꾸준한 생활 습관 유지 |

### 목표 집중 모드에서 추가할 기능

- 단백질 등 특정 영양소의 일일 목표량과 총열량 목표를 일반 모드보다 더 눈에 띄게 보여주고, 섭취할 때마다 진행 상태를 갱신한다.
- 오늘 남은 목표량과 달성률을 바탕으로 다음 식사에서 무엇을 얼마나 보완할지 안내한다.
- 장기 목표를 혼자 유지하기 어려운 점을 고려해, 중단하지 않도록 주기적인 격려와 진행 피드백을 제공한다.
- 닭가슴살처럼 반복 섭취하는 핵심 재료도 다른 조리법과 맛으로 제안해 식단 피로를 줄인다.
- 같은 재료가 지겨울 경우 유사한 영양소를 제공하는 대체 재료를 비교해 선택할 수 있도록 한다.

### 적용 원칙

- 모드는 현재 확정한 핵심 MVP 흐름을 대체하지 않고, 기본 기능 구현 이후 확장한다.
- 각 모드는 완전히 다른 기능 묶음이 아니라 동일한 데이터와 기능을 사용하되 **무엇을 우선 추천하고 어떤 정보를 강조할지**를 다르게 설정한다.
- 서브 타깃별 세부 기능은 고객 근거와 구현 가능성을 추가 검토한 뒤 확정한다. 현재는 목표 집중 모드의 요구사항을 우선 구체화한 상태다.

## 추가 확인이 필요한 사항

- 클라우드 저장 정보의 범위와 건강·개인정보 비식별화 방식
- 냉장고 내 처리, LG 사내·전용 서버, 외부 클라우드 간 역할 분담
- 비전 모델의 재료 인식 범위와 라벨·영수증 OCR의 MVP 포함 여부
- 외식 기록을 모바일에서 입력하고 냉장고가 누락 여부를 확인하는 흐름의 구체화
- 레시피별 재료·조리법 변경이 영양 계산에 미치는 영향을 반영할 데이터 기준
- 자녀 맞춤·식재료 효율·시니어 건강 모드의 세부 기능 및 우선순위 확정
