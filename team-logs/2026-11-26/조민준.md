- 문제: 핸드폰 시험에서 인식 품질이 낮음 → 행동: 지시서 전제(미세조정 모델 교체)가 실제 코드와 다름을 먼저 확인하고, 같은 500장으로 체크포인트·CLIP 재확인·OCR 을 하나씩 비교 → 결과: 1등 정답률 19.8% → 69.0%, 계란 1/25 → 20/25 (공개 상품 사진 기준) → 배운 점: 모델 크기보다 '찾기'와 '구분하기'를 나눈 2단계 구조가 효과가 컸고, 비교 기준을 고정해야 판단할 수 있다
- 문제: 확실하지 않은 라벨이 재고에 그대로 들어감 → 행동: 글씨 우선·0.75 기준·Unknown 사용자 입력, 재고는 사람 확인 후에만 반영되는 A 이벤트 흐름에 연결하고 30개 시나리오로 검증 → 결과: 라벨 정밀도 86.8%, 확인 전·거절 시 재고 불변, 동시 출고 음수 없음 → 배운 점: 인식 정확도와 DB 연동 성공을 분리해 보고해야 한다

## 작성 예시 — 아래 수치는 모두 가상

### 비전 모델

- 목표: 고정된 테스트셋에서 이미지 분류 정확도를 높인다.
- 조건: 동일한 테스트 이미지 200장, 동일 모델·장비·측정 코드. 테스트셋은 튜닝에 사용하지 않았다.
- 시도: 검증셋 기준으로 학습률 `0.001`, `0.0005`, `0.0001` 세 값을 각각 한 번 비교했다. 최종 `0.0005`를 선택했다.
- 결과: 테스트 정확도 `85% → 91%`, **6%p 증가**. 가상 결과이며 실제 측정 근거가 아니다.

### 음성 응답 속도

- 목표: 사용자 발화 종료부터 음성 출력 완료까지의 시간을 줄인다.
- 조건: 동일 장비·음성 샘플 20개, 각 1회, 전체 시간의 중앙값.
- 변경: 예를 들어 모델을 미리 로드하고 출력 토큰 상한을 `300 → 150`으로 조정했다. 두 변경을 함께 적용했으므로 각각의 효과는 따로 알 수 없다.
- 결과: 중앙값 `10초 → 3초`, **7초 감소·70% 단축**. 가상 결과이며 실제 측정 근거가 아니다.
