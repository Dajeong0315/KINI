# 2026-11-26 | 팀 전체 성과 기록

> 여러 팀원이 함께 작성합니다. 아래 내용은 김진아의 기획 기록과 확인된 회의 내용을 바탕으로 정리한 범위이며, 팀 전체의 모든 작업을 포괄하지 않습니다.

## 기획 결과 — 김진아

- 현직자 멘토링을 통해 KINI의 차별화를 단순 냉장고 기능이 아니라 **가족 구성원별 조건을 이해하고 다음 식사 행동까지 연결하는 AI 영양 파트너**로 설명하기로 했다.
- 선제적 식사 확인, 카메라 미인식 재료의 사용자 확인, 라벨·영수증 OCR, 외식 기록의 모바일 보완, 개인정보 익명화 및 서버 처리 구조를 주요 검토사항으로 정리했다.
- 팀 후속 논의에서는 로컬 구조를 처음부터 고정하기보다 클라우드에서 핵심 기능을 우선 구현·시연하는 방향으로 의견을 모았다. 비전 모델 재검증, 레시피 추천, 조리 중 재료 변경 반영을 우선순위로 두었다.
- DCX 분석 결과를 최종 산출문서의 `Ⅲ. 데이터 수집 전략`과 `Ⅳ. 타깃 고객`으로 정리했다. 공개 검색 문서 74,161건을 수집하고 전처리 후 61,130건을 분석했으며, 40개 원군집을 26개 주제로 통합한 기존 분석 결과를 문서화했다.
- 메인 타깃은 단일 군집 순위가 아니라 여러 가족 식생활 군집과 냉장고 사용 맥락을 종합해 **가족 영양 관리형**으로 설정했다. 자녀 맞춤, 다이어트·체중 관리, 식재료 효율, 시니어 건강 식단 관리형을 서브 Actor로 정리했다.
- 기본 서비스 흐름을 유지하면서 서브 Actor별 추천 기준·대화·리포트 강조점을 바꾸는 목적별 모드 확장 방향을 논의했다. 목표 집중 모드의 영양소·칼로리 추적, 지속 격려, 반복 재료 조리법 다양화 및 대체재 기능을 우선 구체화했다.

## 상태와 해석 한계

- DCX 기회점수는 검색 문서의 언급 비중과 감성 분석을 활용한 상대적 탐색 지표이며 전체 소비자의 수요 비율이나 설문 만족도 점수가 아니다.
- 메인·서브 Actor와 조리 대화 기반 기록은 분석 결과와 서비스 맥락을 결합한 기획 판단이다. 실제 사용자 수요나 기능 효과가 직접 검증된 것으로 표현하지 않는다.
- 클라우드 저장 정보, 개인정보 비식별화, Ollama 유지 여부, 서버 비용, OCR의 MVP 포함 여부는 미확정이다.
- 기획 작업이므로 서비스 성능·정확도·사용자 효과는 미측정이다. 위 문서 수와 군집 수는 데이터 처리 규모이며 제품 성능 지표가 아니다.

- AI: 회의 내용 구조화, DCX 자료 정리와 제출 문서 초안 지원
