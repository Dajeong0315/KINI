## 작업 내용과 판단

- 사용자 및 가족의 건강정보, 알레르기, 식단 정보 등을 외부 AI에 그대로 전달하는 구조의 보안 위험을 검토하였다.
- 로컬 LLM을 개인정보 보호 목적으로 활용하고, 외부 LLM은 추천 및 분석 처리에 활용하는 하이브리드 구조를 검토하였다.
- 로컬 데이터베이스와 외부 데이터베이스의 역할 및 저장 데이터 분리 방안을 조사하였다.
- LLM의 판단에만 의존하지 않고 로컬 규칙 엔진과 외부 전송 데이터 제한을 통해 개인정보 보호를 강화하는 방식을 검토하였다.
- 알레르기 등 안전 조건을 로컬에서 검증하고, 외부 AI가 안전 판정이나 영양 수치를 임의로 변경하지 못하도록 추천 처리 경계를 정의하였다.
- 외부 API 요청 시 실제 내부 식별자 대신 요청 단위의 임시 코드를 사용하도록 API 계약 초안을 구성하였다.
- 정상 추천, 안전한 추천 없음, 개인정보 차단, API 오류 및 재검증 필요 상태를 구분하였다.
- 프론트엔드 담당자가 mock 데이터를 활용하여 개발할 수 있도록 API 응답 예시와 전달 사항을 검토하였다.
