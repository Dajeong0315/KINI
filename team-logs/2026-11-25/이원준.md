## 작성 예시 — 아래 수치는 모두 가상

### 비전 모델

- 목표: 고정된 테스트셋에서 이미지 분류 정확도를 높인다.
- 조건: 동일한 테스트 이미지 200장, 동일 모델·장비·측정 코드. 테스트셋은 튜닝에 사용하지 않았다.
- 시도: 검증셋 기준으로 학습률 `0.001`, `0.0005`, `0.0001` 세 값을 각각 한 번 비교했다. 최종 `0.0005`를 선택했다.
- 결과: 테스트 정확도 `85% → 91%`, **6%p 증가**. 가상 결과이며 실제 측정 근거가 아니다.

### 음성 응답 속도

- 목표: 사용자 발화 종료부터 음성 출력 완료까지의 시간을 줄인다.
- 조건: 동일 장비·음성 샘플 20개, 각 1회, 전체 시간의 중앙값.
- 변경: 예를 들어 모델을 미리 로드하고 출력 토큰 상한을 `300 → 150`으로 조정했다. 두 변경을 함께 적용했으므로 각각의 효과는 따로 알 수 없다.
- 결과: 중앙값 `10초 → 3초`, **7초 감소·70% 단축**. 가상 결과이며 실제 측정 근거가 아니다.
