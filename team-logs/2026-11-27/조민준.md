## 포트폴리오 메모

- 문제: 이름 붙인 반찬통을 각도만 바뀌어도 다시 물어봄 → 행동: 재학습 대신 '변화 없는 자리 유지 + 1장→24장 증강 갤러리'로 설계하고, 실제 샘플에서 이웃으로 이름이 번지는 문제를 '이 물체가 아님' 기준과 실측 기준값으로 막음 → 결과: 실제 샘플에서 번짐 0, 3° 회전에도 유지 (실제 용기 정확도는 미측정) → 배운 점: 등록 물체가 하나뿐이면 1·2등 비교가 작동하지 않으므로 비교 상대를 따로 만들어야 한다
- 문제: 인식 결과가 재고 DB 에 반영되지 않음 → 행동: 읽기·쓰기 키 분리, 재고는 RPC 로만 변경, 같은 촬영 중복 방지, 재고 부족은 '확인 필요', 연결 끊김은 대기열 — 가짜 클라이언트·실제 PostgreSQL·실제 Supabase 3단계로 검증 → 결과: 실제 인식(버터 꺼냄)이 실제 DB 에 반영, 키 노출 0 → 배운 점: "테이블이 이미 있다"는 전제도 직접 확인해야 하고(실제로는 없었음), DB 반영 성공과 인식 정확도는 분리해 보고해야 한다
