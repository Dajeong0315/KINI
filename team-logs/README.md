# 팀 작업 기록

날짜별 폴더에 팀원 개인 기록과 `팀 전체.md`를 모읍니다.

## AI에게 요청하기

- **“오늘 기록해줘”** — 본인의 개인 기록을 작성해 `main`에 올립니다.
- **“오늘 팀 기록 통합해줘”** — 팀원 5명의 기록이 모인 뒤 한 사람이 요청해 팀 전체 기록을 정리합니다.
- 날짜를 지정하려면 **“11월 24일 기록해줘”**처럼 말하면 됩니다.

에이전트가 이름을 알 수 없으면 물어볼 수 있습니다. 직접 푸시하려면 저장소 쓰기 권한이 필요합니다. 최신 `main`을 받은 뒤 [에이전트 지침](../AGENTS.md)을 읽을 수 있는 프로젝트 에이전트에서 사용하세요.

## 직접 기록하기

`python team-logs/새_날짜_만들기.py`를 실행하면 한국 시간 기준 오늘의 기록 파일을 만듭니다. 다른 날짜는 명령 뒤에 `YYYY-MM-DD`를 넣으세요. 수동 실행이며 기존 파일을 덮어쓰지 않고, 기본적으로 평일만 생성합니다.
