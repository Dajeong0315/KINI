# 팀 작업 기록

날짜별 폴더 안에 팀원 각자의 기록과 **팀 전체 성과 기록**을 함께 둡니다. 개인 파일은 본인이 그날 수행한 작업과 판단을, 팀 전체 파일은 팀이 공유·검증할 성능 결과와 통합 상태를 기록합니다.

```text
team-logs/
├── README.md
├── 새_날짜_만들기.py
├── templates/
│   ├── 개인_템플릿.md
│   └── 팀_전체_템플릿.md
├── 2026-11-25/
│   ├── 전다정.md
│   ├── 김진아.md
│   ├── 조민준.md
│   ├── 김재웅.md
│   ├── 이원준.md
│   └── 팀 전체.md
├── 2026-11-24/
│   └── 전다정.md
└── ...
```

## 매일 기록하는 방법

1. 팀원은 각자 프로젝트 에이전트에게 **“오늘 기록해줘”**라고 말합니다. 에이전트는 근거를 확인해 본인 개인 파일만 작성하고 `main`에 직접 커밋·푸시합니다. 이름이 불명확하면 물어볼 수 있습니다.
2. 개인 파일에는 그날의 목표, 직접 한 일, AI·팀의 도움, 실험과 결과, 판단·시행착오 및 검증 범위를 남깁니다. 측정하지 않았다면 `미측정`이라고 적습니다.
3. 개인 기록이 모인 후 한 사람이 **“오늘 팀 기록 통합해줘”**라고 요청합니다. 에이전트는 개인 기록을 비교해 `팀 전체.md`에 팀 성과와 측정 조건·근거를 정리하고 그 파일만 `main`에 직접 올립니다. 빈 파일이나 미제출 기록은 표시하고, 결과가 확정되지 않았다면 잠정이라고 적습니다.
4. 직접 작성할 때는 `python team-logs/새_날짜_만들기.py`로 한국 시간 기준 오늘 폴더와 기본 파일 6개를 만들 수 있습니다. 특정 날짜는 뒤에 `YYYY-MM-DD`를 넣습니다. 수동 실행 방식이며 기존 파일은 덮어쓰지 않고 기본적으로 평일만 생성합니다.

저장소에 쓰기 권한이 있어야 직접 푸시할 수 있습니다. 다른 팀원의 변경이나 기존 작업은 보존하고, 원격의 최신 변경을 먼저 확인합니다. 동시에 같은 팀 파일을 수정해 충돌하면 서로의 내용을 합친 후 올립니다.

## AI에게 요청하기

- 개인 기록: **“오늘 기록해줘”**
- 팀 전체 성과 통합: **“오늘 팀 기록 통합해줘”**
- 다른 날짜: **“11월 24일 기록해줘”**, **“11월 24일 팀 기록 통합해줘”**

상세 절차는 [AGENTS.md](../AGENTS.md)에 있습니다. 이 방식은 해당 지침을 읽을 수 있는 프로젝트 에이전트에 적용되며, 접근하지 못한 다른 대화·실험 로그는 자동으로 확인할 수 없습니다. 주말 작업은 사용자가 명시적으로 요청한 경우 기록합니다.

## 수치와 실험 기록 기준

- **성능:** 지표의 정확한 이름과 단위, 변경 전후 값, 절대·상대 변화량을 남깁니다. 예를 들어 정확도 `85% → 91%`는 `6%p 증가`, 응답시간 `10초 → 3초`는 `7초 감소·70% 단축`입니다. 이 숫자는 가상 예시입니다. 정확도, mAP, 재현율 등 서로 다른 지표를 혼용하지 않습니다.
- **측정 조건:** 모델·코드 버전, 데이터 출처·분할·표본 수, 장비, 측정 구간, 반복 횟수와 평균·중앙값·p95 등 집계 방법을 기록합니다. 이전과 이후의 조건이 달랐다면 차이를 밝혀 직접 비교를 피합니다.
- **시행착오:** 하이퍼파라미터 이름, 변경 전 값, 탐색 범위와 간격, 총 시도 횟수, 최종 값, 실패와 부작용을 기록합니다. 둘 이상을 함께 바꿨다면 개별 원인을 단정하지 않습니다.
- **검증 수준:** 실제 연동과 fake/mock, 합성 평가, 실제 사용자 평가를 구분합니다. 측정하지 않은 성능이나 품질을 추정해 채우지 않습니다.
- **근거와 재현:** 실험 스크립트, 명령, 로그, 데이터 버전, 관련 커밋·PR 및 담당·검토자를 연결합니다. 미완료 실험은 잠정 결과로 표시합니다.

## 작성과 공유 원칙

- 본인 작업과 AI·팀원의 기여를 구분하고, 팀 성과는 참여자와 역할을 명시합니다.
- API 키, 개인정보, 원본 음성·대화, 로컬 DB 등 민감 자료는 올리지 않습니다.
- 기존 종합 회고는 2026-11-11부터 2026-11-25까지 평일 날짜별 `전다정.md`로 나누었습니다. 이전에 확인된 주말 날짜의 대화 기록은 해당 날짜를 명시해 다음 평일 파일에 참고자료로 보존했습니다. 확인되지 않은 내용은 미확인으로 표시하며, 다른 팀원의 과거 기록은 각자 추가합니다. 포트폴리오 사례와 출처는 [11월 25일 개인 기록](2026-11-25/전다정.md)에 보존했습니다.
