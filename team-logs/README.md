# 팀 작업 기록

각자 이름으로 폴더를 만들고 하루에 한 파일씩 작성합니다. 예: `team-logs/이름/2026-11-25.md`

[일일 기록 양식](TEMPLATE.md)을 복사해 사용하세요. 목표, 판단 이유, 시행착오, 결과, 검증, 다음 작업과 협업 요청을 남깁니다. 간단한 날은 해당 항목만 적어도 됩니다.

- 본인이 실제로 수행한 일과 AI·팀원의 도움을 구분합니다.
- 계획·진행 중·완료와 테스트 범위를 정확히 표시합니다.
- API 키, 개인정보, 원본 음성·대화, 로컬 DB 등 민감 자료는 기록하지 않습니다.
- 각자 브랜치에서 작성하고 팀의 PR 절차에 따라 공유합니다.

기존 회고는 날짜별 대화와 팀 기록을 종합한 소급 기록이며, 이후에는 날짜별 파일로 이어서 작성합니다.
